# Legal Bulletins 资讯质量标准（v0.3）

对齐上游 [AIHOT](https://github.com/KKKKhazix/AIHOT) 的「预筛宽召回 + 高门槛精选」思路，但读者换成**律师 / 法务 / 合规 / LegalTech**。

## 什么算高质量

一条进入每日读本，至少要同时满足：

1. **法律 × AI 交叉**：正文/标题能同时看到 AI 信号与法律（或法律科技）信号。只谈算力、世赛、网络安全宣传周、外交部空泛治理表态 = 不合格。
2. **实质变化**：产品发布/重大功能、融资与并购、诉讼与判决、正式监管规则、可迁移的律所/法务落地方法。会议展演、座谈会、宣传通稿默认不合格。
3. **可核对摘要**：摘要必须概括事实，禁止正文截断、作者栏、半截英文；涉及条文/判决时提醒回原文。
4. **来源优先级**：英文 LegalTech 垂直媒体与厂商一手研究 > 中文法律科技垂直 > 官媒综合法治（整刊限流）。

## 什么必须压住

| 类型 | 例子 | 处理 |
|---|---|---|
| 产业/算力软文 | 东西部算力互济、词元工厂 | 噪声门拦掉 |
| 赛事/宣传周 | 世赛 AI 赛项、网安宣传周 | 噪声门拦掉 |
| 外交空谈 | 「贡献中国方案」无具体规则 | 噪声门拦掉 |
| 纯安全攻防 | 蜜罐、越狱、众测通报（无法律落地） | 噪声门拦掉 |
| 会议展演 | 产品展演活动、学术研讨会召开 | 刊发分大幅降低 |

## 实现落点

| 组件 | 作用 |
|---|---|
| `server/app/classify.py` | 交叉门、噪声门、注意力评分、入选门槛 |
| `server/app/edition.py` | 每日刊配额、官媒整刊限流、垂直源加权 |
| `server/app/enrich.py` | 答案先行摘要提示词 |
| `references/sources.v1.yaml` | 信源层级与 `must_title`（v0.3 收紧官媒） |
| `server/app/web_cn.py` | 内置中文列表同步收紧 |

## 刊发配额（v0.3）

- 中文 ≤ 8，英文 ≤ 6；监管 ≤ 1
- 官媒/综合法治源整刊 ≤ 2，单源 ≤ 1
- 法律科技垂直源单源 ≤ 3
- 宁缺毋滥：交叉门不过则宁可不发满

## 与 AIHOT Skill 的关系

- 通用 AI 日更继续由 `aihot` Skill（`aihot.news`）覆盖。
- LawHOT 不再试图「也覆盖通用 AI」，只做法律向策展，避免两边抢同一批噪声稿。
